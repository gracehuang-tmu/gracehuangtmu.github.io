menu_book團主使用說明
回點餐頁

第一次設定（只做一次，需用電腦，約 5 分鐘）

啟用後端

  1. 建立 Apps Script 專案：打開 script.google.com → 新專案，刪掉原本的 function myFunction() {}。
  2. 貼上程式並儲存：打開 Code.gs 純文字版，全選複製、貼上，按 Ctrl+S（Mac：⌘+S）。
  3. 執行 setup：工具列函式選單選 setup → 按「執行」，依序授權：審查權限 → 選帳號 → 進階 → 前往（不安全）→ 允許。
    • 下方「執行紀錄」會顯示團主密碼與試算表網址，請記下密碼。
    • 函式選單沒有 setup：通常是還沒存檔，或手機版編輯器不支援。
  4. 部署：右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」；執行身分「我」、存取權「所有人」→ 部署 → 授權存取。
  5. 把網址交給 Claude：複製 https://script.google.com/macros/s/…/exec，貼給 Claude；Claude 會填入 config.js 並送一筆測試訂單確認。
    • 完成後點餐頁上方會顯示「點餐中」，不再出現「尚未開放」提示。
  6. 團主登入：點餐頁右上角 admin_panel_settings 圖示（或「全部彙整」頁底的「團主登入」）→ 輸入團主密碼。同一台裝置會記住登入。

每次揪團

開團到叫貨

  1. 換菜單（換店時才需要）：把新菜單照片傳給 Claude，Claude 辨識後更新頁面菜單。
  2. 設定這次的團：「全部彙整」→「團主設定」，填今日訂購商家、開放訂購時間、截團時間、備註（到貨時間、領取地點）→ 儲存設定。
  3. 清掉上一團的訂單：同一區按「清空訂單」。
  4. 分享連結：把 https://gracehuang-lab.com/drink/ 貼到 LINE 群組。同事不需登入，輸入名字點飲料就會自動送出，截團前可自行修改。
  5. 截團：到截團時間自動關閉；需要提早結束可按「暫停點餐」。
  6. 叫貨：「全部彙整」→「複製清單」，貼給店家；「依人分列」可用來收錢。訂單也會同步在你的 Google 試算表。

常見問題

  1. 同事送不出去：檢查是否已過截團時間或被暫停；否則請對方重新整理頁面。
  2. 忘記團主密碼：回 Apps Script 再執行一次 setup，執行紀錄會再顯示同一組密碼。
  3. 更新了 Code.gs：存檔後要「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」→ 部署，網址不變。
