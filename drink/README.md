# 飲料團購點餐

網址：https://gracehuang-lab.com/drink/

- 前端：`index.html`、`app.js`、`style.css`（GitHub Pages，同事不需登入）
- 後端：`apps-script/Code.gs`（Google Apps Script；訂單、商家菜單存在系統管理員的 Google 試算表，菜單照片存在雲端硬碟「飲料團購菜單照片」資料夾）
- 設定：`config.js` 放 Apps Script 網頁應用程式網址
- `menu.json`：未選商家時的初始菜單

## 系統管理員：第一次設定（只做一次，需用電腦）

1. 到 https://script.google.com 新專案，刪掉 `function myFunction() {}`，貼上 `apps-script/Code.gs` 全文，Ctrl+S 儲存。
2. 函式選單選 `setup` →「執行」，授權：審查權限 → 選帳號 → 進階 → 前往（不安全）→ 允許。執行紀錄會顯示團主密碼與試算表網址。
3. 「部署」→「新增部署作業」→ 網頁應用程式；執行身分「我」、存取權「所有人」→ 部署。
4. 把 `https://script.google.com/macros/s/…/exec` 填入 `config.js`。
5. 菜單照片 AI 解析（Claude，按用量付費）：到 https://platform.claude.com 購買額度並建立 API 金鑰 → Apps Script「專案設定」→「指令碼屬性」新增 `ANTHROPIC_API_KEY` = 金鑰。預設模型 `claude-sonnet-5-5`；想省錢可再新增 `CLAUDE_MODEL` = `claude-haiku-5-5`。
6. 把團主密碼交給要開團的同事（所有團主共用）。改密碼：Apps Script「專案設定」→「指令碼屬性」→ `ADMIN_KEY`。

更新 Code.gs 後：「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」→ 部署，網址不變。

## 團主：每次開團（手機可操作）

1. 點團主邀請連結自動登入（或點餐頁右上角團主圖示 → 輸入團主密碼）。團主專區不會自動更新，看最新訂單請按「更新」。
2. 「今日訂購商家」選單選店家，馬上生效。新的店按「新增商家（上傳菜單）」：填店名、上傳菜單照片 → 儲存。
   - 上傳照片後 AI 會自動解析成可點選的品項，核對價格（[待確認] 是看不清楚的地方）後儲存。也可直接修改文字。
3. 填開放訂購時間、截團時間、備註 →「儲存設定」；上一團的訂單按「清空訂單」。
4. 分享網址給同事。到截團時間自動關閉，可隨時「暫停點餐」。
5. 「團主專區」→「複製清單」貼給店家；「依人分列」用來收錢。

## 資安說明

- repo 公開，程式中沒有密碼或金鑰；團主密碼存在 Apps Script 指令碼屬性。
- 每位同事的瀏覽器有一組隨機憑證，只有本人能改自己的訂單。
- 後端只回傳登記在菜單表裡的照片，不會讀到雲端硬碟其他檔案。
- 寫入試算表的文字會防止公式注入。
